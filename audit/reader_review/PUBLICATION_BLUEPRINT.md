# GitHub 与个人主页传播蓝图

日期：2026-09-19
默认建议：审阅说明用中文；面向国际研究读者的公开稿用英文。这里给内容、信息架构与示例稿，不执行发布，不替作者终选图片或许可。

## 共同的核心叙事

一句话问题：当每个 agent 同时拥有多个、又没有预先排序的收益目标时，均衡不再只是一个点；怎样理解这一整组 Nash states 的几何、动力学、收益后果、坐标表示与有条件的激励设计？

推荐的研究链：

1. **Geometry — T1：** payoff weights 生成 weighted games，进而生成 Nash set；结构可能从 weight simplex 映到 Nash image。
2. **Dynamics — S1/S2：** agents 按局部 pseudo-gradient 选择行动；分支矩阵、特征结构和域转移决定稳定/不稳定与紧/非紧边界。
3. **Welfare — P1：** own improvement、externality 与 total payoff change 不同；弱改善也可能产生跨时刻 trap。
4. **Representation — X1：** 非双射变换可帮助构造 stability certificate，但会坍缩 fibers；pointwise image 不是独立 transformed trajectory。
5. **Design — I1：** 只修改一类 payoff，以 target、omega、sigma、anchoring 和 aggregate budget 设计行为；结论受 theorem assumptions 约束。

这条链既不是“六个互不相关的 MATLAB demo”，也不是“所有图都是论文原图复刻”。它同时含 paper-parameter cases、legacy-rule cases、new constructions、independent renderings 和 schematic。

> # Vector-Payoff Games: From Nash-Set Geometry to Incentive Design
>
> In a scalar-payoff game, each agent optimizes one ordered objective. Here each agent has several payoff components without a fixed preference between them. The equilibrium is therefore generally a **set generated by admissible payoff weights**, not a single point.
>
> This repository reconstructs a connected line of results: how the weight domain maps to a Nash set; how piecewise pseudo-gradient dynamics can stabilize or destabilize that set; why own improvement can differ from total payoff improvement; what a non-bijective coordinate transformation preserves or collapses; and what a budget-constrained incentive design can guarantee under explicit assumptions.

简短 alt text：

#### 2. “Why a set?” 概念桥

用一个不超过 10 行的符号块：

- `J_j^i`：agent `i` 的 objective `j`；
- `w^i`：agent `i` 在自己的 payoff components 上的非负权重；
- weighted game：每个 agent 最大化 `sum_j w_j^i J_j^i`；
- `X*(J)`：所有允许权重对应的 Nash states 的并；
- 在 T1 条件下，每个 weight 通过 `M(w)x+b(w)=0` 产生一个 state，且 `M` 和 `b` 必须使用相同权重。

紧接一句边界：有限点云/网格只检查实现；全局 one-to-one/onto 依赖论文条件。

P1 关键比较示例稿：

> **Own improvement is not total payoff improvement.** The selected pseudo-gradient makes an agent move along one of its own payoff gradients, so the own-direction contribution is nonnegative. A payoff also changes because the other agent moves. We therefore evaluate
> `total payoff rate = own-direction contribution + externality`.
> The three constructed games hold the trajectory family fixed while changing linear externality terms, separating a nonweak case, an all-payoff-nondecreasing case, and a weak-but-not-all case. The trap is a fourth, separate legacy-rule experiment: it asks whether both payoff components can be worse at a later time even while a weak condition holds locally.

P1 trap caption 示例：

> **A cross-time weak-Pareto trap under the actual legacy scaled-own-gradient rule.** The middle panel compares agent 2’s two payoff components at `t1=0.020` and `t2≈1.819`; both are lower at the later sampled time. The right panel decomposes each total rate into own and externality contributions. This is finite-grid evidence for this trajectory, not a continuous-time theorem and not a substitute for the separate nonweak example.

#### 5. 统一符号与证据层级

建议新建 `docs/CONCEPTS_AND_NOTATION.md`，至少包含：

| 符号/术语 | 含义 | 常见误读 |
|---|---|---|
| `J_j^i` | agent `i` 的 objective `j` | 上下标不能交换 |
| BR | 单个 objective 的 own-gradient zero/best-response line | 不是一条全局 trajectory |
| selected pseudo-gradient | 当前 branch 决定的 state update | 不等于 full payoff gradient |
| own contribution | `partial J / partial x_i * xdot_i` | 不等于 total `dJ/dt` |
| externality | `partial J / partial x_-i * xdot_-i` | 可改变 total rate 符号 |
| Gamma | 对 sensitivity 不敏感的 positive-externality certificate region | 不等于实际 total-rate region Omega |
| Omega | total payoff rate 非负的区域 | 依赖实际 dynamics |
| `eta(x(t))` | 原轨迹的逐点映像 | 不等于独立积分 `z(t)` |
| `sigma`,`omega` | budget topology / weighted stationarity 与 Nash-boundary placement 的参数 | 不可跨不同游戏作单因素因果比较 |

证据徽标只用四类：

- theorem/paper identity；
- exact algebra/branch calculation；
- clean MATLAB execution；
- finite sampling or schematic。

## B. GitHub 个人主页精选图文叙事

主页目标不是复现，而是让访问者在 30–90 秒回答：作者研究什么？为什么有趣？最关键的认识是什么？如何深入？

### B1. 推荐短叙事

#### 1. Motivation — one agent, several objectives

英文示例：

> **What changes when a player has several objectives but no fixed ranking among them?** Instead of a single Nash point, admissible objective weights can generate a geometric set of equilibria. My work studies how that set is shaped, how decentralized dynamics move around it, and when welfare-oriented incentives can change the outcome without hiding their budget cost.

候选图：`T1_production_pollution`。
链接：仓库 “Why a set?”。

#### 2. Geometry — a set, not a point

候选图：cube/prism 的一张简化二联派生图；production 图保留应用语境。
短 caption：

> Weight-domain faces can correspond to faces of a weighted Nash image under the paper’s regularity conditions. The colored region is a decentralized Nash object, not a centralized Pareto frontier.

#### 3. Dynamics and welfare — local motion can mislead

候选图：P1 trap 中间面板，旁边配一张精简 own/externality/total 分解。
短文：

> Moving uphill along an agent’s selected objective does not determine the total change of every payoff: the other agent’s motion creates an externality. A locally weak condition may therefore coexist with a later state where both components are worse than at an earlier time.

链接：仓库 P1 technical section。

#### 4. Representation — transformations also discard information

候选图：`X1_fiber_collapse`，建议提升为主页候选。
短 caption：

> A non-bijective coordinate map collapses whole fibers of original states to one axis point. This can support a stability certificate, but the inverse is set-valued and a mapped original trajectory is not automatically the trajectory of an independently integrated transformed system.

#### 5. Design — behavior, welfare and budget together

候选图：`I1_before_after` 左上轨迹面板 + 右下 aggregate transfer 的简化双联图。
短 caption：

> The incentive changes only one payoff component per agent and redirects the trajectory toward a target region. The design is reported together with original payoffs and aggregate transfer; the numerical case illustrates checked conditions and observed behavior, not an unqualified theorem guarantee.

#### 6. Deep links

三个按钮：

- Read the research story
- Reproduce the MATLAB experiments
- Read the papers

论文按钮只能指向作者确认可公开的 DOI/版本，不链接本地 PDF。
