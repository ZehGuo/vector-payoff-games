## 1. 结论摘要

1. 论文记号 `J_j^i` 的**上标 `i` 是 agent，下标 `j` 是 objective**；状态按 `x=[x^1,x^2]^T` 排列，agent 1 控制第一坐标，agent 2 控制第二坐标。MATLAB 名字采用 agent-first 拼接：`A12,b12,J12` 对应论文 `J_2^1`，不是 `J_1^2`。
2. 完整梯度、own-gradient 和选定的 pseudo-gradient 是三种不同对象。pseudo-gradient 的两个坐标分别由每个 agent 的规则选出一条 own-gradient，不能把四个 own-gradient 直接拼成二维 RHS。
3. T(3.8)、ACC(7)按到两条 BR 的距离选分支；`cdc2024` 与 GitHub trap helper 按 scaled own-gradient 的绝对值选分支。对同一 agent，若 `alpha_1^i |A_ii^{i1}| = alpha_2^i |A_ii^{i2}|`，两种排序对所有 active 点相同；不满足时只能逐点判断，不能把两规则当同一公式。
4. Q1 的主要差异已定位。T4.3(b)纸面字面参数在 `x0=(0,0)` 给出零 RHS；实际 `cdc2024/test6_4_1.m` 按旧代码顺序把纸面视觉顺序中的两项中间收益归给了相反的 agent/objective，并另改了部分 `b`，在相同初值给出 RHS `(15,0)`。作者所说实际仿真不会停止与源码一致，原因是**参数/对象归属版本不同**，不是旧审计所称的 own-gradient。
5. 最小未解问题仅剩：现有材料不能唯一确认 Fig.4.3 三个子图的绘图究竟来自现存 legacy 版本还是另一个未留存版本。此问题只影响“精确纸面复现”标签，不是已确认论文缺陷，也不阻塞 S1/P1 等独立工作。

## 2. 可复用记号契约

论文二次收益为

`J_j^i(x) = 1/2 x^T A^{ij} x + (b^{ij})^T x + c^{ij}`，其中 `i` 是 agent，`j` 是 objective。两 agent 标量状态时：

| 论文对象 | 含义 | MATLAB 变量 | own 控制坐标/行 |
|---|---|---|---|
| `J_1^1`, `A^{11}`, `b^{11}` | agent 1 / objective 1 | `J11`, `A11`, `b11` | `x1=x^1` / row 1 |
| `J_2^1`, `A^{12}`, `b^{12}` | agent 1 / objective 2 | `J12`, `A12`, `b12` | `x1=x^1` / row 1 |
| `J_1^2`, `A^{21}`, `b^{21}` | agent 2 / objective 1 | `J21`, `A21`, `b21` | `x2=x^2` / row 2 |
| `J_2^2`, `A^{22}`, `b^{22}` | agent 2 / objective 2 | `J22`, `A22`, `b22` | `x2=x^2` / row 2 |

这与 T p26 的 `J^i=[J_1^i,J_2^i]^T`、T p55 三组公式的视觉上/下标及 ACC p2 式(3)一致。PDF 抽取顺序不能用于重排中间两项。

### 2.1 四类导数量

- **完整梯度**：`grad J_j^i = A^{ij}x+b^{ij}`，是对全部状态的二维向量。
- **own-gradient**：`h_j^i = partial J_j^i / partial x^i = e_i^T(A^{ij}x+b^{ij})`，标量状态下是完整梯度的第 `i` 分量。源码中的未缩放 own-gradient 是 `A11(1,:)*x+b11(1)`、`A12(1,:)*x+b12(1)`、`A21(2,:)*x+b21(2)`、`A22(2,:)*x+b22(2)`。
- **pseudo-gradient**：`f=(f^1,f^2)`。每个 `f^i` 由 active/inactive 判定和分支选择规则从 `alpha_j^i h_j^i` 中选一个，或置零。它不是任何单一收益的完整梯度，也不是四个 own-gradient 的直接拼接。
- **收益的总时间导数**：`dJ_j^i/dt = (grad J_j^i)^T f = h_j^i f^i + (partial J_j^i/partial x^{-i}) f^{-i}`。第一项是 own-direction contribution，第二项是 externality；`h_j^i f^i >= 0` 不推出完整 `dJ_j^i/dt >= 0`。

## 3. 两种分支规则

令 `a_j^i=A_ii^{ij}<0`，则

`h_j^i = a_j^i (x^i-BR_j^i(x^{-i}))`，因此 BR 距离为 `rho_j^i=|h_j^i/a_j^i|`。

### 3.1 最近 BR（T(3.8)、ACC(7)、E(27)的意图）

对 agent `i`：

1. 两个 own-gradient 同为正或同为负时为 active；选择 `rho` 较小的目标，并令 `f^i=alpha_j^i h_j^i`。
2. 两个 own-gradient 异号时处于不能同时严格改善两目标的区域，令 `f^i=0`。
3. T(3.8) 与 ACC(7)在距离相等时选 objective 1（`<=`）；E(27)两条 active 分支都写成严格不等号，未单独定义 tie。`ifac_extention/testfun2.m` 用 `<=` 落到 objective 1，补足了代码 tie 行为。
4. 当一个 own-gradient 为零时，论文的闭域记号会在边界重叠；最近距离分支选中零 own-gradient，故数值 RHS 仍为零。legacy helper 直接因乘积不大于零返回零。应把“边界标签可能不同”和“向量场值相同”分开记录。

### 3.2 scaled-gradient（`cdc2024`、`acc2025`、GitHub helpers）

源码先构造 `d_j^i=alpha_j^i h_j^i`，仅当两个 `d` 乘积严格为正时，返回绝对值较小者；否则返回零。绝对值相等时通过 `<=` 分支选择 objective 1。`cdc2024`/GitHub 接口固定 `alpha_1^1=alpha_1^2=1`，仅传入 `alpha12,alpha22`。

最近-BR 比较的是 `|h_j^i|/|a_j^i|`，scaled-gradient 比较的是 `alpha_j^i|h_j^i|`。若

`alpha_1^i |a_1^i| = alpha_2^i |a_2^i|`，

则两个 scaled 值都是同一正常数乘以对应 BR 距离，因而 active 区的排序和 tie 完全一致。反之，两规则的切换阈值一般不同；它们仍可能在某个具体点偶然选中同一分支。
