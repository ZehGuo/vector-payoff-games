## 4. Unified notation, provenance, axes, and wording

The integrated contract is:

- `J_j^i`: superscript `i` is agent, subscript `j` is objective; code records
  use agent-first names `J11,J12,J21,J22` only when the ordering is declared.
- State axes are `x^1,x^2` (or the declared higher-dimensional coordinate);
  transformed axes are `eta^1(x),eta^2(x)` and the independently integrated
  transformed trajectory is `z(t)`; time axes are `t`.
- Red/blue BR curves identify agents 1/2; purple denotes the declared Nash set
  or weighted Nash image. A centralized social Pareto set is never called Nash.
- Original/new, paper/legacy, and schematic parameters are labeled separately.
  New S1/S2/P1 constructions are not called exact source-figure recovery.
- Nearest-BR and scaled-own-gradient rules retain their literal names. The trap
  remains the actual scaled-rule legacy version.
- Plot windows, scaling, and legends are local to the scientific comparison;
  equal visual axis ranges are not imposed across games with different state
  scales. Within each comparison group, paired panels use the same coordinates
  or explicitly state when they do not.
- “Observed”, “sampled”, “verified identity”, “theorem application”, and
  “schematic” remain distinct conclusion levels.

The R1 pack uses clean MATLAB renderings. The three committed P1 figures remain
the previously documented independent-renderer presentation; the pack contains
the corresponding MATLAB-generated figures. They agree on experiment identity
and numerical conclusions but are not byte-identical or visually identical, so
neither is mislabeled as the other.
