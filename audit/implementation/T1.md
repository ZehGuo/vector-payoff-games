## 1. 交付与结论

- 入口：`experiments/run_t1_topology_applications.m`；独立参数登记：`experiments/configs/t1_topology_parameters.m`。
- cube：权重域`Delta^1 x Delta^1 x Delta^1`与weighted Nash像并列，6面、12边、8顶点同色同号对应。
- triangular prism：权重域`Delta^2 x Delta^1`与weighted Nash像并列，5面、9边、6顶点同色同号对应。
- 应用：Example 2.11生产/污染控制的四条BR与紫色weighted Nash image；没有计算或命名集中式社会Pareto集。
- 非二次边界：Figure 2.6没有完整函数/参数，交付图显式写明“schematic only”，不声称数值复现。

所有数值点都由

`M(lambda) x*(lambda) + b(lambda) = 0`

求得，`M`和`b`使用同一权重同时组合。实现没有继承legacy cube固定`M`、仅加权`b`的缺陷。

## 2. 记号与参数版本

沿用M0：`J_j^i`上标`i`是agent，下标`j`是objective。Chapter 2给出的是controlled-coordinate partial derivative blocks；本任务只保存这些block及offset，不凭own rows补齐完整收益Hessian。因此这里不存在可由代码解释为“原始社会福利”的人造二次函数。

### 2.1 Cube：Example 2.9 paper版

状态`x=[x^1,x^2,x^3]^T`，每个agent控制一个坐标、具有两个objective。`w_i`加权`J_1^i`，`1-w_i`加权`J_2^i`。按agent 1–3、objective 1–2排列的own rows/offset为：

| agent | objective 1 `(row; offset)` | objective 2 `(row; offset)` |
|---|---|---|
| 1 | `[-1,0,.4]; 0` | `[-1,0,-.6]; 5` |
| 2 | `[1,-2,.4]; 0` | `[1,-2,-.5]; 6` |
| 3 | `[0,0,-1.5]; 0` | `[0,0,-1]; -10` |

legacy `acc2024/cube`把objective 2末系数写成`+.6/+.5`，并在每个权重点固定`M=[a11;a21;a31]`。T1采用paper字面`-.6/-.5`并重算`M(w)`与`b(w)`；两版本均登记但不混跑。

### 2.2 Triangular prism：Example 2.10 paper版

状态`x=[x_1^1,x_2^1,x^2]^T`。agent 1控制前两坐标、具有三个objectives，权重`lambda=(lambda_1,lambda_2,lambda_3)`；agent 2控制第三坐标、具有两个objectives，权重`q,1-q`。

| 对象 | controlled block/row | offset |
|---|---|---|
| `J_1^1` | `[-1,0,.5; 0,-1,0]` | `[0;0]` |
| `J_2^1` | `[-1,0,.5; 0,-2,0]` | `[0;5]` |
| `J_3^1` | `[-1,0,0; 0,-2,.5]` | `[6;0]` |
| `J_1^2` | `[-1,.5,-2]` | `0` |
| `J_2^2` | `[-1,.5,-2]` | `6` |

legacy prism两条agent-2 row的首系数为`+1`；paper为`-1`。legacy本身同时加权`M/b`，所以固定矩阵缺陷只属于cube，不能扩大到prism。T1运行paper版。

## 3. 全部面的对应

权重为零表示从相应加权标量问题中删去该objective；该权重面的像就是相应子博弈的weighted Nash像。

| 域 | 面 | 条件 | 子博弈含义 |
|---|---|---|---|
| cube | F1/F2 | `w_1=0/1` | 删除`J_1^1`/删除`J_2^1` |
| cube | F3/F4 | `w_2=0/1` | 删除`J_1^2`/删除`J_2^2` |
| cube | F5/F6 | `w_3=0/1` | 删除`J_1^3`/删除`J_2^3` |
| prism | P1/P2 | `q=0/1` | 删除`J_1^2`/删除`J_2^2` |
| prism | P3 | `lambda_1=0` | 删除`J_1^1` |
| prism | P4 | `lambda_2=0` | 删除`J_2^1` |
| prism | P5 | `lambda_3=0` | 删除`J_3^1` |

图中边是两个面条件的交，顶点是三个面条件的交；同一个编号在权重域和状态像中表示同一个权重及其`x*(weight)`。运行结果另写出`results/t1/t1_face_correspondence.csv`、`t1_edge_correspondence.csv`和`t1_vertex_correspondence.csv`。

## 4. 满射与双射

- 满射：把`X*(J)`定义为这些权重标量化问题的解像时，每个像点至少有一个权重原像；不同权重仍可能落到同一点。
- 双射：除满射外还要求权重原像唯一，才能逐顶点、边、面无折叠地对应。
- Examples 2.9/2.10正文明确说Theorem 2.4条件成立，`x*`是从cube/prism到`X*(J)`的diffeomorphism，因此本任务两例采用双射/结构保持身份。MATLAB有限采样的非零Jacobian和分离顶点是实现诊断，不能代替该全局定理结论。

这一区分也解释了为什么单一Nash点云不足：点云能显示“像”，但不能独自证明哪个面、边、顶点来自哪个权重子域，也不能排除多对一。

## 5. 生产与污染应用

Example 2.11的完整纸面公式为：

- `J_1^1=(100-2(x^1+x^2))x^1-5(x^1)^2`，`J_2^1=150-3(x^1)^2`；
- `J_1^2=(100-2(x^1+x^2))x^2-4(x^2)^2`，`J_2^2=140-2.5(x^2)^2`。

利润目标推动正产量，环境目标的own最佳响应是零产量。两agent各自标量化自己的两个objectives后求解两条own stationarity equations，得到图中的紫色weighted Nash image。它是非合作向量收益博弈的Nash像，不是把四个收益集中加权后求出的社会Pareto集。
