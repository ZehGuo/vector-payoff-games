## 1. Result and evidence boundary

This task reconstructs the IFAC-extension Section V example from equations
(27), (28), (43), (50), and (58)–(62). It does **not** treat the legacy
workspace scripts or `reference/previous_prototype/` as the correct baseline.
The printed certificate was checked first. It passes with strict margins, so no
new certificate was fitted or solved for.

Three different objects are retained throughout:

1. `x(t)` is integrated from the original pseudo-gradient ODE.
2. `eta(x(t))` is evaluated pointwise from those already integrated original
   states. It is a mapped curve, not another ODE solution.
3. `z(t)` is integrated independently from `z(0)=eta(x0)` using the transformed
   piecewise-linear right-hand side (50). No mapped samples or interpolation of
   `eta(x(t))` are used to construct it.

The committed trajectory figure labels all three sources directly. The local
runtime CSV preserves them in distinct columns.

## 2. Sources and parameter contract

State order is `x=[x^1,x^2]^T`; superscript is agent and subscript is objective.
The implementation uses the paper's four complete quadratic parameter records:

| payoff | `A` | `b` | sensitivity |
|---|---|---|---:|
| `J_1^1` | `[-2,-1;-1,-3]` | `[8;0]` | `alpha_1^1=.5` |
| `J_2^1` | `[-4,-4;-4,-12]` | `[30;0]` | `alpha_2^1=.25` |
| `J_1^2` | `[-7,1;1,-2]` | `[4;0]` | `alpha_1^2=5` |
| `J_2^2` | `[-3,1;1,-1]` | `[12;0]` | `alpha_2^2=1` |

The legacy `ifac_extention/original_trajectory.m` replaces the external first
entries `4` and `12` by zero. Those entries do not enter agent 2's own-gradient,
the BR distances, `eta`, or either ODE, so this difference does not change X1's
dynamics. The separate `ecc2026` parameter set was inspected but not mixed into
this experiment.

The nearest-BR rule is the paper rule. If an agent's two own-gradients have
opposite signs or zero product, its coordinate is inactive and both its original
velocity and transformed coordinate are zero. In a positive-product active
domain, the smaller absolute BR distance is used; an equality selects objective
1, matching the legacy `<=` behavior.

The missing legacy `testfun3` is replaced by a local, self-contained
`transformedRhs` derived directly from (50)–(51). It does not read any workspace
variable. For a transformed coordinate exactly on an axis, the forward ODE uses
the declared convention `z_i<=0 -> objective 1`, `z_i>0 -> objective 2`. This is
a deterministic forward boundary rule only; it is **not** an inverse map.

## 3. Original domains and their images

Within the paper's assumed simply connected neighborhood `D_1^1 ∩ D_1^2`, the
domain map is:

| original domain | transformed image |
|---|---|
| `D^(1,1)` | negative/negative quadrant |
| `D^(1,2)` | negative/positive quadrant |
| `D^(2,1)` | positive/negative quadrant |
| `D^(2,2)` | positive/positive quadrant |
| `D^(1,0)`, `D^(2,0)` | negative and positive `eta^1` half-axes |
| `D^(0,1)`, `D^(0,2)` | negative and positive `eta^2` half-axes |
| `D^(0,0)=X*(J)` | origin |

The first X1 figure displays the nine original domains beside these four
quadrants, four half-axes, and the origin. A full-active-grid check found 3,505
points inside this assumed sign/objective correspondence and obtained a zero
chain-rule residual between `D eta(x) f(x)` and the selected transformed branch.
Another 1,876 full-active points in the large plotting box lie outside that
local sign map and were deliberately not used to claim a global quadrant
correspondence. This is an assumption boundary, not a numerical failure.

The restrictions to one-active original domains have rank one. Every point of a
line segment parallel to the relevant BR can therefore have the same point on a
transformed axis. The code never calls `testfun3_3` and never returns an arbitrary
original representative for an axis point.

## 4. Printed certificate checked before integration

The four-decimal matrix printed after (62) was used literally:

```
T = [ 6.2058 -1.0547 -2.5757  0.1138
     -1.0547  4.3862  3.9895  0.6236
     -2.5757  3.9895  6.2058 -2.8365
      0.1138  0.6236 -2.8365  4.3862 ]
U = W = [0 1; 1 0].
```

`U` and `W` are entrywise nonnegative, as Proposition 3 requires. They are not
being asserted positive semidefinite. For each branch,
`P_(j1,j2)=F_(j1,j2)' T F_(j1,j2)`. The following are the exact eigenvalue
margins from the independent calculation, reproduced by MATLAB:

| branch | `max eig(Atilde'P+P Atilde+E'UE)` | `min eig(P-E'WE)` |
|---|---:|---:|
| `(1,1)` | `-42.2760428149` | `2.2440811913` |
| `(1,2)` | `-20.6210429469` | `8.9129869617` |
| `(2,1)` | `-17.2933944690` | `2.7333156523` |
| `(2,2)` | `-12.6690660020` | `7.0510770080` |

Thus the global strict decay margin is `12.6690660020` and the strict positivity
margin is `2.2440811913`, despite rounding of the printed `T`. Both are far above
the numerical tolerance. A new certificate is unnecessary. The old
`Solve_lmi.m` was not run: it omits the strict `U` term in the decay inequalities,
uses non-strict constraints, depends on YALMIP/workspace state, and is not needed
to verify a certificate already printed by the paper.

The four `P` pieces agree exactly on their shared axes in this arithmetic, so the
piecewise quadratic `V` is continuous there. Note also that the prose calculation
below (61) drops a minus sign when bounding `Vdot`; the implemented check follows
the actual strict matrix inequality (58), which yields
`Atilde'P+P Atilde < -E'UE` and hence strict decay off the origin.

## 5. The three trajectories and separation interval

MATLAB integrates both ODEs separately with fixed-step classical RK4,
`dt=.001`, `t in [0,5]`, from `x0=(6.5,-10)`. The independent checker uses its
own NumPy/RK4 transcription with `dt=.0002`.

The formula-based initial image is

`eta(x0)=(-2.5,-13.25)`,

not the paper's printed `(-2.5,-13.5)`. Direct substitution into the displayed
`J_1^2` own row gives `(-.5*x^1+x^2)=-13.25` after normalization; MATLAB and the
independent checker agree. The printed value is retained as a source discrepancy,
not silently substituted into the independent ODE.

| result | MATLAB `dt=.001` | independent `dt=.0002` |
|---|---:|---:|
| first separation above `1e-3` | `t=.047` | `t=.0462` |
| maximum `||eta(x(t))-z(t)||_2` | `5.5267024482` | `5.5319270687` |
| first one-active interval | `[.047,.174]` | `[.0462,.1740]` |
| original branch on interval | `(0,1)` | `(0,1)` |

On the MATLAB A-to-B interval, `x(t)` moves vertically while its image remains on
the negative `eta^2` axis, from `(0,-8.3005040531)` to `(0,-2.3310440151)`.
Meanwhile the independently integrated `z(t)` leaves the axis and evolves in a
two-dimensional quadrant. This is the displayed separation segment. The paper
text states `||eta(x_A)||<||eta(x_B)||`; for the labels shown in Figure 6 and both
recomputations the values decrease from A to B, so that printed inequality is
reversed. This does not affect the certificate or stability implication.

The Euclidean norm of an eta-space curve can temporarily increase: MATLAB counts
134 positive `>1e-8` steps for `||eta(x(t))||_2`. That is not an instability
certificate. In contrast, both `V(eta(x(t)))` and `V(z(t))` have zero positive
steps above `1e-8` in the MATLAB run. The transformed contours and the original
grid pullback `V(eta(x))` are plotted explicitly.

## 6. Applicability boundary and relation to S1

Three statements must not be merged:

- **The original system is unstable** is a property of its actual dynamics. S1
  Case 5 has a positive eigenvalue ray that stays in the selected active cone;
  that is direct instability evidence. A coordinate map cannot remove it.
- **This sufficient condition is inapplicable** means an assumption, sign/domain
  correspondence, or strict LMI certificate is unavailable. That gives no
  conclusion by itself about stability or instability. A failed solver search
  would likewise not prove instability.
- **The non-bijective map loses information** means whole original line segments
  can share an axis image. Consequently `eta(x(t))` need not satisfy the
  independently defined transformed ODE after a one-active transition. This
  explains the split without saying that either system is unstable.

For this particular example, Assumptions 1–2, the local domain correspondence,
and the strict four-branch certificate are the basis for applying the paper's
sufficient stability implication. The result is not generalized to S1's five
cases, to full-active points outside the assumed sign map, or to the separate
`ecc2026` game.
