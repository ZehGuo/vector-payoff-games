# Vector Payoff Games — Audit and Rebuild

This is a clean workspace for rebuilding the MATLAB research code associated with Zehui Guo's work on vector-payoff games, Pareto improvement, stability, and incentive design.

The first phase is an evidence-based audit. Do not refactor MATLAB code until the paper–figure–experiment manifest has been reviewed.

## Local source material

The `source_material/` and `reference/` directories are local research inputs. They are intentionally excluded from Git so that a future public repository does not accidentally publish PDFs, legacy archives, generated output, or prototype material.
